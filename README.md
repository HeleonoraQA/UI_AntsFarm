# Муравьиная ферма

Небольшой лендинг/дашборд на Next.js для наблюдения и управления колонией муравьёв: королева, солдаты и рабочие с именами, автоматический подсчёт численности и хранение состояния в локальном `data.json`.

## Запуск

```bash
npm install
npm run dev
```

Приложение будет доступно на [http://localhost:3000](http://localhost:3000).

## Vercel

Деплой: [ants-farm.vercel.app](https://ants-farm.vercel.app)

> На Vercel изменения колонии не сохраняются между запросами/деплоями, так как `data.json` хранится в файловой системе рантайма. Для постоянного хранения нужно внешнее хранилище.
